# SaaS Customer Support Workflow Improvement

## Business Analysis Portfolio Case Study

> A fictional SaaS case study demonstrating Business Analysis techniques across stakeholder analysis, process mapping, requirements analysis, process improvement, UAT and KPI analysis.

---

## 📌 Project Overview

**SupportFlow** is a fictional SaaS customer support platform used to manage customer tickets, issue categorization, assignment, SLA tracking, escalations and resolution workflows.

This project analyzes the existing customer support workflow, identifies process gaps and pain points, and proposes an improved future-state workflow.

---

## 🎯 Business Problem

The existing support workflow relies heavily on manual ticket categorization, assignment and escalation.

Key challenges include:

- Incomplete information when tickets are created
- Incorrect or delayed ticket routing
- Repeated customer communication
- SLA and resolution delays
- Inconsistent Engineering handoffs
- Limited visibility into recurring customer issues

---

## 🎯 Project Objective

The project aims to:

- Analyze the current support workflow
- Identify pain points and process gaps
- Understand stakeholder needs
- Define business and functional requirements
- Design an improved To-Be process
- Create user stories and acceptance criteria
- Define UAT scenarios
- Establish operational KPIs
